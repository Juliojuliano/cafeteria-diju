# Cafeteria DiJu

Site de página única da Cafeteria DiJu: café artesanal, doces caseiros e salgados desde 2018.

## Como ver

Abra `index.html` no navegador. Não precisa de instalação nem de build: HTML, CSS e JavaScript ficam num arquivo só.

## Publicar no GitHub Pages

Em **Settings → Pages**, escolha **Deploy from a branch**, selecione `main` e a pasta `/ (root)`.

## Seções

- Cardápio com filtro por categoria (Cafés, Doces, Salgados, Bebidas)
- Nossa História, com contadores animados
- Depoimentos
- Contato, com formulário validado (o envio ainda é simulado; ligue a um serviço como Formspree para receber as mensagens)
